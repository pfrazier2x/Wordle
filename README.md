Wordle

Submitted by: Preston Frazier

Wordle is a simple Android word-guessing game built in Kotlin. The user has three chances to guess a random four-letter word. After each guess, the app shows whether each letter is correct, misplaced, or not in the target word.

Required Features

The following required functionality is completed:

User has 3 chances to guess a random 4-letter word.

After 3 guesses, the user can no longer submit another guess.

After each guess, the user sees the correctness of the guess.

O = correct letter in the correct position

+ = correct letter in the wrong position

X = letter is not in the target word

After all 3 guesses are taken, the target word is displayed.
